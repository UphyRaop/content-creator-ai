# Phase 7 regression and acceptance test plan

**Task:** P7-QA-PLAN-01 (CCAI-05-QA)  
**Status:** Drafted before Phase 7 implementation; no checks in this plan have been run.  
**Scope:** Phase 7 Video Timeline and Editor only. All generation, analysis, transitions, and motion previews remain simulated and free. Do not enable live provider calls or spend the RM20 test budget.

## Test approach

Run the headless checks against pure timeline/editor functions and browser storage/import helpers where possible. Use a browser for stateful user flows, actual media playback, layout, touch, and visual preview fidelity. Keep an existing project copy for destructive-case checks. Confirm every generated or analyzed result is labelled as simulated/estimated. No transition/motion or timeline test may invoke rendering or a paid provider.

For precision assertions, define and document the editor's timebase and rounding rule first (prefer integer frames or integer milliseconds internally). Use a single canonical project with two approved scenes, multiple approved speech segments, a deliberate silence region, and known durations; add edge cases with no audio, unequal speech lengths, fractional duration, and a one-scene project. Expected timelines below refer to the stated fixture, not a report of tested behavior.

## Automation boundary

**Good headless candidates:** pure time arithmetic and rounding; ordering and speech-overlap validation; gate predicates; caption cue bounds/order; silence recommendation decisions without applying edits; state immutability for project-only edits; undo/redo reducer histories; schema migration/defaulting and import validation; serialization round trips; quota/error-path handling through mocked browser storage. Keep these deterministic and provider-free.

**Requires browser/manual QA:** actual narrow viewport behavior and touch gestures; keyboard focus and accessible controls in context; real browser quota behavior and recovery; media playback and scrubbing; visual transition/motion preview fidelity; reload flows with browser-local storage; usability of labels, warnings, and simulated/estimated provenance. Browser automation may cover repeatable portions, but visual fidelity and physical touch still need manual review on a real device when available.

## Assumptions and blockers

- Phase 7 is the timeline/editor only; rendering, post-production, thumbnail, and export phases remain out of scope.
- Upstream approval gates and RM0 simulation policy from `AGENTS.md` and `ROADMAP.md` continue to apply.
- Current checkout contains completed Phase 1–6 source and has no `docs/` directory yet. The timebase, editor schema, caption policy, silence heuristic, available previews, supported browser list, and storage strategy are not implemented/confirmed; define them before converting these expectations into exact assertions.
- No test has been run as part of this plan. Mobile viewport emulation was previously unavailable in recorded QA; physical-device/browser coverage is an implementation-stage dependency.
